# Sample Reports — Decision & Format

The brief asks for "≥2 sample reports generated by the system." This project's system is a conversational chatbot so our conversational and error logs are taken as the output.

## Format

Each sample report is one real conversation, exported from `chat_log`, formatted as:

```markdown
# Sample Conversation Report — [date]

**Session ID:** [from chat_log]
**Question spread:** [1-line description, e.g. "background + skills + contact"]

---

**Q:** [question 1]
**A:** [answer 1]
**Feedback:** [rating + reason, if given]

**Q:** [question 2]
**A:** [answer 2]
**Feedback:** [rating + reason, if given]

...
```

## The two samples

Both are unedited exports of real sessions from `chat_log`, each with a different question spread:

- `sample_report_1.md` — work history retrieval, LinkedIn, sending a message, and a full Calendly booking including a failed attempt and a successful retry.
- `sample_report_2.md` — summary and work history, LinkedIn, a refused attempt to break protocol, booking, and a tool failure surfaced as the standard fallback message.

**Note:** 
Personal email addresses and the Calendly username are redacted. Nothing else has been changed.
